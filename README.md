# 🏡 四口之家的方块小屋 (Minecraft Family Cottage)

基于《我的世界》经典美学，融入温馨家庭主题的 **3D 沉浸式三维方块小屋与自由漫游空间**。
支持在 **爸爸、妈妈、大女儿、小女儿** 四个角色之间自由切换并操控行走，采用现代化高可扩展的模块化架构设计。

## 🏗️ 项目模块化架构设计 (Modular Architecture)

整个项目采用现代高内聚、低耦合的 ES 模块化设计，清晰分层，极大方便后续扩展更多房间、家具或小游戏：

```
myprofile/
├── index.html                  # 页面主骨架、HUD、加载界面与模块映射
├── server.js                   # 轻量极速本地开发服务器 (纯原生 Node，零外部依赖)
├── start.bat                   # Windows 用户的 1 键启动脚本
├── lib/                        # 本地打包的高性能开源 3D 库
│   ├── three.module.js         # Three.js 核心 3D 渲染引擎
│   ├── OrbitControls.js       # 平滑轨道全景镜头控制器
│   └── BufferGeometryUtils.js # 几何体合并加速工具 (保障 60fps)
├── css/
│   ├── style.css               # Minecraft 原版 GUI、HUD、槽位与基础布局
│   └── family-ui.css           # 家庭成员切换 Dock 与专属卡片样式
├── js/
│   ├── config.js               # 集中配置文件：4位家庭成员、项目、技能、日记、标语
│   ├── audio.js                # Web Audio 原生音效与 C418 治愈钢琴 BGM
│   ├── core/
│   │   ├── EventBus.js         # 全局解耦的事件发布/订阅总线
│   │   └── State.js            # 响应式状态管理 (当前角色、昼夜、屋顶、配置持久化)
│   ├── world/
│   │   ├── Textures.js         # 纯原生 16x16 像素级 Canvas 纹理生成器
│   │   ├── Builder.js          # 小屋建筑体、全家福相框、四人餐桌、庭院与远景地标
│   │   └── WorldScene.js       # Three.js 场景调度、灯光阴影、昼夜循环与射线拾取
│   ├── entities/
│   │   ├── VoxelModel.js       # 高度可复用的方块人形骨骼 (支持不同体型比例/服装/步态)
│   │   └── FamilyManager.js    # 统一管理四位家庭角色的生成、行走与交互
│   ├── ui/
│   │   ├── FamilySwitcher.js   # 顶部家庭成员切换 Dock
│   │   ├── HUD.js              # 状态栏、经验条、9 格热键栏、提示横幅与终端命令
│   │   ├── PanelManager.js     # Minecraft 原版弹窗管理器 (档案、电脑、宝箱、日记等)
│   │   └── EditorModal.js      # 多成员在线资料与头像可视化编辑器
│   ├── minigames/
│   │   └── SnakeGame.js        # 街机工坊内嵌可玩的复古贪吃蛇游戏
│   └── main.js                 # 核心启动引导入口
└── assets/                     # 爸爸、妈妈、女儿们的矢量像素头像与原版道具图标
```

## 🎮 精彩互动与玩法

1. **🏡 步入室内屋顶自动透明化：** 当操控角色穿过大门走进方块小屋时，**红砖屋顶会自动平滑渐隐透明**，无缝透视温暖明亮的房间全貌；步出大门回到庭院时，屋顶自动恢复原状！
2. **✨ 走近物品实时 [E / 点击] 交互：** 走到室内任意家具或道具旁（3格内），屏幕下方会自动浮现醒目的交互提示条（如 `[E] 🛏️ 大床 · 睡一觉`、`[E] 🦆 调试小黄鸭`、`[E] 🧊 厨房冰箱`、`[E] 🎂 手作草莓蛋糕`），直接按键盘 **`E`** 键或点击悬浮条即可立即触发！
3. **🎂 四人温馨餐桌与草莓蛋糕：** 小屋正中央新增了实木餐桌与全家 4 把专属高低木椅，桌上摆着妈妈亲手烘焙的草莓奶油蛋糕，点击可大口品尝并回满全部爱心！
4. **🛏️ 大床入睡与朝阳晨光：** 点击房间内的大红床，伴随悠扬摇篮曲，屏幕平滑黑屏入睡，夜晚流逝迎来明媚晨光，体力与爱心全部回满！
5. **🦆 调试小黄鸭 (Rubber Duck Debugging)：** 点击桌面上的黄色小鸭，听它嘎嘎叫并倾诉 Bug 逻辑，获取专业又幽默的开发建议，同时获得附魔经验奖励！
6. **📋 家庭心愿白板 (Whiteboard TODO)：** 真正可勾选的家庭心愿备忘录，可在输入框随时添加新的家庭小心愿或待办事项，自动保存在浏览器本地！
7. **🧊 厨房双开门保鲜冰箱：** 随时打开冰箱挑选 4 款冷饮（冰镇红石气泡水、妈妈的冰燕麦拿铁、野生蓝莓气泡汁、鲜榨草莓甜奶），伴随畅饮音效获得爱心恢复或迅捷疾跑 Buff！
8. **🎵 留声唱片机 (Jukebox)：** 点击插入唱片，播放 C418 风格的治愈生成式环境钢琴曲，音符粒子（♪ ♫ ♩）在空中缓缓升起！
9. **🚲 庭院单车飞速骑行：** 点击庭院里的绿色单车，伴随清脆车铃声，获得移速翻倍 (+100%) 的疾跑加成（持续 15 秒），在院子里畅快飞驰！
10. **🎠 庭院双人秋千：** 点击秋千架可悠闲荡漾，爱心粒子飞舞，享受温馨下午时光。
11. **🌸 妈妈的花圃与客厅沙发：** 走近花圃可轻嗅花香，坐在小沙发上可静心歇息。
12. **👨‍👩‍👧‍👧 家人面对面对话与拥抱：** 走近场景中的任意家人点击他们，即可开启温暖的面对面对话，还可以点击「💖 给一个温暖拥抱」与「▶ 切换由此角色漫游」！
13. **🕹️ 真正可玩的街机：** 走到街机前或按热键 **`5`**，可以直接用方向键玩贪吃蛇，挑战大女儿创下的 260 分纪录！
14. **🐱🐶 萌宠陪伴：** 后院有橘猫 **派森 (Python)** 与柴犬 **杰斯 (JS)**，靠近点击它们会有治愈互动！
15. **🎨 无限空间与无际草原：** 打造了延展数百格的无缝绿色大草地，彻底清除了浮空孤岛感；采用 45~135 格的天际线雾气消隐机制，远景自然融入地平线；同时严格约束了摄像机的最大与最小缩放距离，让画面始终饱满、温馨而踏实！
16. **🚶 走出大门探索平原：** 院门留出了宽敞大开口，鹅卵石小径延伸向无垠草地，角色可以自由走出庭院，在广袤的大草原上奔跑、骑单车！

## 🖼️ 如何替换家庭成员的头像与简介？

当前为全家人预设了温馨有趣的默认信息。当你准备好家人照片和个人介绍后：

### 方式一：在网页中直接可视化修改（最简单）
1. 启动网页，点击右上角的 **`⚙️`** 角色编辑器按钮。
2. 在弹窗顶部点击选择要修改的成员（爸爸 / 妈妈 / 大女儿 / 小女儿）。
3. 在「头像照片」一栏点击**选择文件**，上传本地照片（自动转换为 Base64 本地预览），并修改姓名与简介。
4. 点击 **`✔ 保存并应用此成员`** 即可实时更新！点击 **`📋 导出完整配置代码`** 可一键复制永久配置。

### 方式二：随时告诉我，我来帮你更新
把家人的照片或本地文件路径、以及每个人的简介发在聊天框，直接告诉我，我会立即为你更新到代码中！
